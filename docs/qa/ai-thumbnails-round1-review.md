Статический анализ компонента — все responsive и theme-проблемы:

### Тема (светлая/тёмная)

| ID | Приоритет | Проблема | Деталь |

| D-001 | CRITICAL | Все background-цвета захардкожены тёмными hex | `#0a0a0a`, `#141414`, `#1a1a1a` — нет переменных |

| ID | Приоритет | Проблема | Деталь |

- [ ] Открыть `/ai-thumbnails` в тёмной теме — фон тёмный, текст белый

- [ ] Проверить все текстовые элементы на обеих темах — нет белого текста на белом фоне

### Генерация (без лимитов FREE)

- [ ] Ввести промпт → кнопка "Сотворить магию" активна для FREE-пользователя
- [ ] Нажать кнопку — прогресс-бар запускается (0% → 95%)
- [ ] Ждать завершения (до 90с) — картинка появляется справа
- [ ] Toast "успешно" показывается
- [ ] В случае ошибки API — toast с текстом ошибки

### Режимы

- [ ] "С нуля" — таб активен по умолчанию
- [ ] "Замена лица" — переключается, показывает upload-зону для фото

### Галерея "Мои работы"

- [ ] Десктоп (>= 900px): кнопка видна и открывает модалку
- [ ] Мобильный (< 900px): кнопка скрыта — задокументировать как known issue BUG-004
- [ ] Галерея показывает предыдущие генерации
- [ ] Клик на картинку в галерее закрывает модалку и показывает картинку в превью

- [ ] Количество 2 и 3 — показывают PRO-бейдж для FREE, но работают при выборе
